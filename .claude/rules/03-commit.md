# Kural 03: Commit

**Severity:** error · **Stages:** commit-only

## Kural 1 — Conventional Commits (İngilizce)

```
<type>(<scope>): <short imperative subject in English>

Why: <optional motivation, 1-3 sentences>
```

Başlık ve gövde **İngilizce** (kodla tutarlılık). Kullanıcıya dönen sohbet metni Türkçedir; commit
istisnadır. Başlık imperative, ≤ 72 karakter, sonda nokta yok.

## Kural 2 — AI atfı (varsayılan: KAPALI)

Varsayılan olarak commit'e AI co-author / "generated by" satırı **eklenmez**
(kullanıcının `fire-and-water` konvansiyonu). Bir projede açıkça istenirse `Co-Authored-By` eklenebilir
— bu, proje-özel bir `06-…` kuralı veya `CLAUDE.md` notu ile override edilir.

```text
varsayılan:  (atıf satırı yok)
opt-in:      Co-Authored-By: <model> <noreply@anthropic.com>
```

## Type kataloğu

| Type | Kullanım | SemVer |
|------|----------|--------|
| `feat` | yeni özellik | MINOR |
| `fix` | bug düzeltme | PATCH |
| `docs` | sadece doc | — |
| `refactor` | davranış değişmeden yapı | — |
| `test` | test ekleme/düzeltme | — |
| `build` | toolchain, docker, deps | — |
| `chore` | config, scaffold | — |
| `perf` | performans | PATCH |
| `style` | format/whitespace | — |
| `revert` | önceki commit'i geri al | — |

`BREAKING CHANGE:` footer veya `type!` → MAJOR.

## Commit + push davranışı

- **Commit ve push birlikte yapılır**; commit veya (normal) push için ayrı izin istenmez. Kullanıcının
  konvansiyonu: "commit push beraber". `git push --force` bu kuralın dışındadır — **yasak**
  (bkz. [02-guvenlik.md](02-guvenlik.md)).
- **Sıralı commit** — işler biriktirilmez; mantıksal birim başına bir commit (ve push).
- Commit öncesi `git diff --staged` incelenir.

## Doğru örnek

```text
feat(domain): add AABB intersection for tile collision

Why: broad-phase overlap checks are needed before resolving
player-tile collisions.
```
